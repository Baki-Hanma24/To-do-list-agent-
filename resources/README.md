# resources

Reference material you want the agents to draw from: notes about you, your preferences, examples you like, source documents.

Drop `.md` or `.txt` files here, for example:
- `about-me.md`: your city, budget habits, family members, favorite stores
- `writing-examples.md`: emails you've written that sound like you

The agents read every file in this folder (except this README) on every task, so they stop guessing. Keep each file short; very long files get cut off.

**Don't put passwords or account numbers here.** These files are sent to Claude with each task.
